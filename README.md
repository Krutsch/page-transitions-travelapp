# Page Transitions Travelapp

👋, hello there! This repository is a re-write with hydro-js and router-dom of Sarah Drasner's orginal work with Vue & Nuxt.

Live demo: https://page-transitions-router.netlify.app

## Build security

`npm run build` computes CSP SHA-256 hashes from the final HTML and writes the
matching policy to `build/_headers`. Deploy the generated HTML and headers from
the same build.
